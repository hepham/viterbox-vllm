## Key Implementation Decisions

### 1. Alignment Stream Analyzer (vLLM)
- **Decision:** Implement token-based analyzer instead of attention-based
- **Rationale:** vLLM's optimized attention kernels don't expose attention weights
- **Implementation:** EOS suppression, max frame length, consecutive token repetition detection

### 2. Speech Positional Embeddings
- **Decision:** Document limitation rather than implement
- **Rationale:** vLLM's KV-cache architecture makes per-token position tracking complex
- **Impact:** Minimal quality degradation observed in practice

### 3. Viterbox Focus
- **Decision:** Skip Russian/multilingual testing, focus on Vietnamese/English
- **Rationale:** User's primary use case is Viterbox for vi/en

### 4. API Version
- **Decision:** Release as v0.2.0 with stable public exports
- **Exports:** ChatterboxTTS, all exception classes
