## Key Implementation Decisions

### 1. Per-Request CFG Scale
- **Decision:** Encode CFG scale into the conditionals tensor at position `CFG_SCALE_ENCODING_DIM=0`
- **Rationale:** vLLM's multimodal pipeline doesn't support custom per-request parameters directly
- **Implementation:** `cond_emb_with_cfg[0, CFG_SCALE_ENCODING_DIM] = cfg_scale`

### 2. Error Handling Strategy
- **Decision:** Created custom exception hierarchy in `exceptions.py`
- **Classes:** `ChatterboxError`, `ModelLoadError`, `InferenceError`, `AudioProcessingError`, `ConfigurationError`, `VLLMError`
- **Pattern:** All exceptions include `suggestion` field for actionable messages

### 3. Batch Edge Case Handling
- **Decision:** Graceful degradation instead of assertions
- **Changes:** Added validation for empty embeddings, short token sequences, embedding count mismatches
- **Behavior:** Logs warnings but continues processing when possible
